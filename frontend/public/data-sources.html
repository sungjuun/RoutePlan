날씨: Open-Meteo

날씨 자동 조회 시 숙소 좌표가 Open-Meteo에 전달됩니다. 일별 날씨와 강수확률을 요약하고 수동 예보는 보존합니다. 최대 16일 예보이며 실제 날씨·운영 여부를 보장하지 않습니다. 무료 endpoint는 비상업용입니다.

장소와 도로 경로: Google Maps

장소 검색어·검색 중심 좌표·선택 장소 ID 또는 이동 경로의 좌표·출발시각이 Google에 전달됩니다. 브라우저 지도를 열면 Google 지도 서비스와 직접 통신합니다. Google 영업시간은 정규 주간 정보로 공휴일·임시 휴무를 보장하지 않습니다. 실제 도로 경로는 Google 지도에 표시하며, 기본 방문순서 선과는 다릅니다.

개인 여행 정보와 커뮤니티

이메일·닉네임과 해시된 비밀번호, 여행·예산·지출, 선택한 취향은 RoutePlan 서버에 저장합니다. 비밀번호 원문은 저장하지 않습니다. 취향 추천은 관심사·지역·여행 방식의 일치 점수를 사용하고 외부 AI로 보내지 않습니다. 지출은 공개 루트에 포함하지 않습니다. 댓글·후기는 공개되므로 예약번호·연락처 같은 개인정보를 작성하지 마세요. 후기는 실제 방문 인증을 거치지 않습니다.

신고 내용은 지정된 운영자만 검토하며 숨김 처리한 글은 데이터베이스에서 보존됩니다. 운영 서비스 공개 전에는 운영 주체·문의처·보유 기간·삭제 절차 등 실제 운영 정책을 별도로 확정해야 합니다. 현재 이 페이지는 외부 연동에 대한 개발용 안내입니다.
